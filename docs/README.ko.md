# Persona Tags

SillyTavern용 페르소나 관리 기능 강화 확장 프로그램입니다.

페르소나 목록이 많아질수록 어떤 페르소나가 무엇인지 구분하기 어려워집니다. 이 확장 프로그램을 사용하면 페르소나에 태그를 붙이고, 태그별로 필터링하며, 일괄 작업과 자유로운 순서 정렬을 통해 깔끔하게 정리하고 쉽게 찾을 수 있습니다.

## 주요 기능

### 태그 시스템
- 페르소나에 태그 추가 (쉼표로 구분하여 한 번에 여러 개 추가 가능)
- 오른쪽 열에 펼쳐 볼 수 있는 **기존 태그** 빠른 선택기 (현재 페르소나에 이미 추가된 태그는 자동으로 숨겨지며, 태그가 많을 때 부드럽게 스크롤됨)
- **포함**(일치하는 항목만 표시) 및 **제외**(일치하는 항목 숨기기) 모드로 태그별 페르소나 필터링
- 필터 패널에서 태그를 길게 눌러 드래그로 순서 변경
- 현재 캐릭터에 연결된 페르소나가 사용 중인 태그가 은은하게 강조 표시됨
- 각 페르소나 카드에 태그 직접 표시
- 새 페르소나 생성 창에서 초기 태그를 바로 추가 가능

### 일괄 관리
- **일괄** 버튼을 클릭해 모든 카드에 체크박스가 표시되는 일괄 편집 모드로 전환
- **전체 선택** / **선택 해제**
- 일괄 **태그 추가**, 일괄 **태그 삭제**, 일괄 **삭제** 지원

### 정렬 및 순서 지정
- 페르소나 카드를 길게 눌러 드래그로 순서 변경 (모바일 환경 지원)
- 오른쪽 열에 정확한 위치 번호를 입력해 바로 이동
- 모든 카드에 현재 위치 번호 표시
- **전체** 보기와 각 개별 캐릭터/그룹에 연결된 페르소나별로 독립적인 정렬 순서 유지

### 보기 및 탐색
- **연결됨** 보기: 현재 캐릭터 또는 그룹에 연결된 페르소나만 표시
- **전체** 보기: 모든 페르소나 표시
- 상단 **↑ / ↓** 빠른 스크롤 이동: 지정한 수의 페르소나만큼 이동 (기본값 `10`, 세션 간 설정 유지); `0.5s` 동안 길게 누르면 맨 위 또는 맨 아래로 바로 이동
- 목록을 다시 불러오는 수동 새로고침 버튼
- 목록 보기 및 격자 보기 모두 지원

### 다국어 지원 및 기타 기능
- **SillyTavern 공식 UI 언어 17종** 전체 완벽 지원 — SillyTavern 언어 설정에 따라 자동 적용 (미지원 또는 추후 추가되는 언어는 영어로 대체)
- 페르소나 복제 시 **태그 복사** 및 **연결 복사** 선택 체크박스 제공
- 동일한 캐릭터에 여러 페르소나가 연결된 경우 아바타, 이름, 태그를 함께 표시하는 향상된 다중 페르소나 선택 팝업
- 페르소나 백업 및 복원 시 태그, 사용자 지정 정렬 순서, 빠른 스크롤 설정이 자동으로 포함됨

## 설치 방법

### 방법 1: SillyTavern 내에서 바로 설치 (권장)

1. SillyTavern을 열고 **확장**(상단 바의 큐브 아이콘)을 클릭합니다
2. **확장 프로그램 설치**를 클릭합니다
3. 아래 저장소 URL을 붙여넣고 설치한 뒤 페이지를 새로고침합니다:

```
https://github.com/XiaoBai20001212/persona-tags
```

> 이후 업데이트는 **확장 프로그램 관리**에서 바로 설치할 수 있습니다.

### 방법 2: 수동 설치

저장소를 다운로드하여 압축을 푼 뒤, `persona-tags` 폴더 전체를 다음 경로에 넣으세요:

```
SillyTavern/public/scripts/extensions/third-party/persona-tags/
```

페이지를 새로고침하면 바로 사용할 수 있습니다.

## 데이터 저장

태그 및 정렬 데이터는 기존 페르소나 데이터를 수정하지 않고 SillyTavern의 `extension_settings`에 저장됩니다. 확장 프로그램 폴더를 삭제하면 SillyTavern에 아무런 영향 없이 기본 UI로 깔끔하게 복원됩니다.
