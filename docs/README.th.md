# Persona Tags

ส่วนขยายจัดการเพอร์โซนาขั้นสูงสำหรับ SillyTavern

เมื่อรายการเพอร์โซนาของคุณมีจำนวนมากขึ้น การจำว่าใครเป็นใครก็ยิ่งทำได้ยากขึ้น ส่วนขยายนี้ช่วยให้คุณติดแท็กเพอร์โซนา กรองตามแท็ก จัดการเป็นชุด และจัดเรียงลำดับได้อย่างอิสระ เพื่อให้ทุกอย่างเป็นระเบียบและค้นหาง่ายอยู่เสมอ

## ฟีเจอร์เด่น

### ระบบแท็ก
- เพิ่มแท็กให้เพอร์โซนา (คั่นด้วยจุลภาคเพื่อเพิ่มหลายแท็กพร้อมกัน)
- ตัวเลือกด่วน **แท็กที่มีอยู่** แบบพับเก็บได้ในคอลัมน์ด้านขวา (ซ่อนแท็กที่มีอยู่บนเพอร์โซนาปัจจุบันโดยอัตโนมัติ พร้อมการเลื่อนที่ลื่นไหลเมื่อมีแท็กจำนวนมาก)
- กรองเพอร์โซนาตามแท็กได้ทั้งโหมด **รวม** (แสดงเฉพาะที่ตรงกัน) และ **ยกเว้น** (ซ่อนที่ตรงกัน)
- กดค้างที่แท็กในแผงตัวกรองเพื่อลากและจัดเรียงลำดับใหม่
- แท็กที่เพอร์โซนาซึ่งเชื่อมโยงกับตัวละครปัจจุบันใช้อยู่จะเรืองแสงจางๆ
- แสดงแท็กโดยตรงบนการ์ดเพอร์โซนาแต่ละใบ
- เพิ่มแท็กเริ่มต้นได้ทันทีภายในหน้าต่างสร้างเพอร์โซนา

### การจัดการเป็นชุด
- คลิก **ชุด** เพื่อเข้าสู่โหมดแก้ไขเป็นชุด พร้อมช่องทำเครื่องหมายบนการ์ดทุกใบ
- เลือกทั้งหมด / ล้างการเลือก
- เพิ่มแท็กเป็นชุด ลบแท็กเป็นชุด และลบเพอร์โซนาเป็นชุด

### การจัดเรียงและลำดับ
- กดค้างที่การ์ดเพอร์โซนาเพื่อลากและจัดเรียงลำดับใหม่ (ใช้งานสะดวกบนมือถือ)
- กรอกหมายเลขตำแหน่งที่ต้องการในคอลัมน์ด้านขวาเพื่อย้ายไปยังตำแหน่งนั้นโดยตรง
- แสดงหมายเลขลำดับปัจจุบันบนการ์ดทุกใบ
- แยกลำดับการจัดเรียงอย่างอิสระระหว่างมุมมอง **ทั้งหมด** และเพอร์โซนาที่เชื่อมโยงของตัวละคร/กลุ่มแต่ละรายการ

### มุมมองและการนำทาง
- มุมมอง **ที่เชื่อมโยง**: แสดงเฉพาะเพอร์โซนาที่เชื่อมโยงกับตัวละครหรือกลุ่มปัจจุบัน
- มุมมอง **ทั้งหมด**: แสดงเพอร์โซนาทั้งหมด
- ปุ่มเลื่อนด่วน **↑ / ↓** ด้านบน: ข้ามทีละจำนวนเพอร์โซนาที่กำหนดเอง (ค่าเริ่มต้น `10` และบันทึกค่าข้ามเซสชัน); กดค้าง `0.5s` เพื่อกระโดดไปบนสุดหรือล่างสุดทันที
- ปุ่มรีเฟรชด้วยตนเองสำหรับโหลดรายการใหม่
- รองรับทั้งมุมมองรายการและมุมมองตาราง

### ภาษาและฟีเจอร์เพิ่มเติม
- รองรับภาษาอินเทอร์เฟซทางการของ SillyTavern ครบทั้ง **17 ภาษา** โดยอิงตามการตั้งค่าภาษาใน SillyTavern ของคุณโดยอัตโนมัติ (หากเป็นภาษาที่ยังไม่รองรับหรือภาษาใหม่ในอนาคต จะสลับกลับเป็นภาษาอังกฤษให้อัตโนมัติ)
- ช่องทำเครื่องหมายเพิ่มเติมสำหรับ **คัดลอกแท็ก** และ **คัดลอกการเชื่อมโยง** เมื่อทำสำเนาเพอร์โซนา
- ป๊อปอัปเลือกหลายเพอร์โซนาแบบปรับปรุงใหม่ แสดงรูปโปรไฟล์ ชื่อ และแท็ก เมื่อมีหลายเพอร์โซนาเชื่อมโยงกับตัวละครเดียวกัน
- การสำรองและกู้คืนข้อมูลเพอร์โซนาจะรวมแท็ก ลำดับการจัดเรียงที่กำหนดเอง และการตั้งค่าการเลื่อนด่วนไว้โดยอัตโนมัติ

## การติดตั้ง

วางโฟลเดอร์ `persona-tags` ลงใน:

```
SillyTavern/public/scripts/extensions/third-party/persona-tags/
```

รีเฟรชหน้าเว็บก็พร้อมใช้งานได้ทันที

## การจัดเก็บข้อมูล

ข้อมูลแท็กและการจัดเรียงจะถูกเก็บไว้ใน `extension_settings` ของ SillyTavern โดยไม่แก้ไขข้อมูลเพอร์โซนาเดิมของคุณ หากลบโฟลเดอร์ส่วนขยายออก หน้าตา UI เริ่มต้นจะกลับมาเป็นปกติทันทีโดยไม่ส่งผลกระทบต่อ SillyTavern
