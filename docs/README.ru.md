# Persona Tags

Расширение для улучшенного управления персонами в SillyTavern.

Когда список персон становится большим, в них легко запутаться. Это расширение позволяет добавлять теги к персонам, фильтровать по тегам, выполнять пакетные операции и свободно менять порядок сортировки, чтобы всё оставалось аккуратным и легко находилось.

## Возможности

### Система тегов
- Добавление тегов к персонам (через запятую можно добавить сразу несколько)
- Раскрывающийся быстрый выбор **Существующие теги** в правой колонке (автоматически скрывает теги, уже добавленные к текущей персоне, с плавной прокруткой при большом количестве тегов)
- Фильтрация персон по тегам в двух режимах: **Вкл** / Включить (показывать только совпадающие) и **Искл** / Исключить (скрывать совпадающие)
- Удерживайте теги в панели фильтров, чтобы перетаскивать их и менять порядок
- Теги, используемые персонами, привязанными к текущему персонажу, мягко подсвечиваются
- Отображение тегов прямо на каждой карточке персоны
- Добавление начальных тегов непосредственно в окне создания персоны

### Пакетное управление
- Нажмите **Пакет**, чтобы перейти в пакетный режим с флажками на каждой карточке
- **Выбрать все** / **Сбросить** выделение
- Массовое добавление тегов, массовое удаление тегов и массовое удаление персон

### Сортировка и порядок
- Долгое нажатие на карточку персоны для перетаскивания и изменения порядка (удобно на мобильных устройствах)
- Ввод точного номера позиции в правой колонке для быстрого перемещения
- Отображение текущего порядкового номера на каждой карточке
- Независимый порядок сортировки для вкладки **Все** и для персон, привязанных к каждому отдельному персонажу или группе

### Режимы просмотра и навигация
- Вкладка **Связанные**: показывает только персоны, привязанные к текущему персонажу или группе
- Вкладка **Все**: показывает все персоны
- Верхние кнопки быстрой прокрутки **↑ / ↓**: переход на заданное количество персон (по умолчанию `10`, значение сохраняется между сессиями); удержание `0.5s` перематывает сразу в начало или в конец списка
- Кнопка ручного обновления для перезагрузки списка
- Поддержка как режима списка, так и режима сетки

### Локализация и прочее
- Полная поддержка всех **17 официальных языков интерфейса SillyTavern** с автоматическим переключением по настройкам SillyTavern (для неподдерживаемых или будущих языков используется английский)
- Дополнительные флажки **Копировать теги** и **Копировать привязки** при дублировании персоны
- Улучшенное всплывающее окно выбора персоны, отображающее аватар, имя и теги, если к одному персонажу привязано несколько персон
- Резервное копирование и восстановление персон автоматически включает теги, пользовательский порядок сортировки и настройки быстрой прокрутки

## Установка

Поместите папку `persona-tags` в каталог:

```
SillyTavern/public/scripts/extensions/third-party/persona-tags/
```

Обновите страницу — расширение готово к работе.

## Хранение данных

Данные о тегах и сортировке сохраняются внутри `extension_settings` SillyTavern и не изменяют исходные данные ваших персон. Удаление папки расширения полностью возвращает стандартный интерфейс, не затрагивая SillyTavern.
